# Physics 1 Trainer

Parametric practice for PHY2048 (Exam 2 focus, Exam 1 review). Static site:
no backend, progress in `localStorage`.

```
npm install
npm run dev      # local dev server
npm test         # vitest (golden + property + engine tests)
npm run build    # tsc + vite build
```

Deploys to GitHub Pages from `main` via `.github/workflows/deploy.yml`
(repo Settings → Pages → Source: GitHub Actions).

See `CLAUDE.md` for the project spec, `CONTENT_GUIDE.md` for how to add
questions, and `PROGRESS.md` for status.
